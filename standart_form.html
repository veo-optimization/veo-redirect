Для особистого акаунту:
1. Telegram → Налаштування.
2. Натисніть Ім’я користувача (на iPhone — спершу «Редагувати»).
3. Придумайте ім’я: латиниця, цифри або _, від 5 символів.
4. Натисніть ✓ / «Готово».

Для каналу чи групи:
1. Відкрийте канал або групу → натисніть на назву вгорі.
2. Редагувати (олівець) → Тип каналу / Тип групи.
3. Оберіть Публічний і впишіть посилання t.me/…
4. Збережіть.
